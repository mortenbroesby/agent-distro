# Agent Distro specifications

The specification system separates executable work from history:

- `active/` — current epics and their checklists.
- `part/` — scoped, ready follow-up parts not currently being implemented.
- `done/` — completed, evidence-backed records.
- `roadmap/` — the one-page status tracker.

[`../pointer.md`](../pointer.md) is orientation only; a clear user request can
start work outside its current focus.
