# Agent Distro for GitHub Copilot

Install curated, evidence-driven agents and skills from the Agent Distro marketplace. The plugin includes empty MCP and hook templates; configure them deliberately after installation.

## Install

```sh
copilot plugin marketplace add mortenbroesby/agent-distro
copilot plugin install agent-distro@agent-distro-marketplace
```

For a direct development install, use:

```sh
copilot plugin install mortenbroesby/agent-distro:plugins/agent-distro
```
